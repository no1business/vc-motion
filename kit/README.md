# motion-kit — 전문가급 숏폼 모션 부품

세로 1080×1920, 60fps. 모든 부품은 `seek(t)` 순수 함수(시간만으로 화면 계산)라서 서브프레임 렌더로 진짜 모션 블러가 나온다.

## 구성
- `core.js` — 공통 도우미: 이징·스프링·결정적 난수·노이즈, 글자→점 샘플링(`textPoints`), 블룸(`makeBloom`), 필름 그레인
- `m01_lightpoint.js` — 빛 한 점 오프닝 (블룸·렌즈 광선·빛의 링·도트 매트릭스 글자 → 가로선 → 여러 줄)
- `m02_slitscan.js` — 슬릿 스캔 글자 (선 → 글자 조각 띠가 엇갈려 조립 → 찢어지며 다음 단어)
- `m03_particles.js` — 입자 → 글자 (세 색 소용돌이 충돌 → 섬광 → 글자로 수렴 → 바람에 흩어짐)
- `m04_checklist.js` — 대행 서비스 '처리되는 느낌' (헤드라인·서류 카드 슬롯 숫자·도장·플러드·문장 모핑·칩 체크리스트)
- `m05_droptype.js` — 튀는 공 + 잔상 + 손글씨 주석 + 낙하 착지 글자
- `m06_embers.js` — 문서 글자 → 불씨 (약관 위 빛 → 종이가 타며 글자가 금빛 불씨로 떠올라 구체로)
- `m07_fluid.js` — 유체 마블링 + 글자 (WebGL 셰이더)
- `m08_orbits.js` — 의미 있는 궤도 고리 (글자·파형·체크 고리, 레이더 카운트다운)
- `m09_chrome.js` — 크롬 3D 방패 + 2줄 헤드라인 (three.js, ES 모듈)
- `m10_echo.js` — 에코 스택 → 기울어진 타이포 월 → 강조 띠 플러드
- `m11_kinetic.js` — 뜻대로 움직이는 단어(늘어나요·튀어요·돌아요·딱!·멈춰요.) + 모서리 이징 곡선
- `m12_graph.js` — 빛나는 선 그래프 + 선 높이 연동 카운트업 + 선택 박스·말풍선 → 카메라 돌진 → 강조색 덮기
- `m13_cards.js` — 3D 카드 필드 → 한 장이 걸어 나와 뒤집힘(예약 확정 카드) → 워프
- `m14_wipes.js` — 전환 세트(세로 블록·대각선 컷·버튼 눌림→덮기·원·블라인드) + 리스트 누적
- `m15_prism.js` — three.js 유리 프리즘 → 빛이 갈라져 채널 칩 5개 (ES 모듈)
- `m16_flap.js` — 스플릿 플랩 보드(공항 출발판) → 강조 줄만 남아 빛이 지나감
- `m17_loader.js` — 눈금 원형 로더 0→100%(계단식) + 확인 항목 누적 → '승인 완료' 도장
- `m18_sunrise.js` — (v2 고급형) 수평선 한 줄 → 아래에서 은은한 빛 → 글자가 해처럼 떠오르며 역광 → 광택 반사·글자 위 빛 한 번 (해 원반·방사형 빛줄기 금지)
- `m19_fold.js` — 전개도 6칸이 접혀 3D 상자 → 들려 돌고 착지 (ES 모듈)
- `m20_strike.js` — 비싼 선택지에 빨간 펜 취소선 → 새 가격이 위·아래 반쪽 두 색으로 맞물림 → 형광펜·손글씨
- `m21_width.js` — 가변 폭 글자(Archivo wdth, DOM 렌더) '24/7' 숨쉬기 → 7줄 폭 물결 → 한 줄만 남음
- `m22_dots.js` — 도트 매트릭스 글자 → 점이 왼쪽부터 떠올라 다음 단어로 다시 모임
- `m23_ink.js` — 한지 위 먹물 번짐으로 세로 글씨(WebGL 마스크) + 붉은 낙관 (Noto Serif CJK KR 필요 — 고객 PC엔 웹폰트로)
- `m24_clock.js` — 시계 하루 24시간 빨리 감기 + 하루 색 고리 + 시각별 할 일 칩
- `m25_chat.js` — 새벽 문의 → 입력 중 → 자동 답장 + 예약 카드 (DM 자동화용)

## 완성 영상 예시 (부품을 참고해 새로 설계)
- `films/ins_v1.html` + `plans/film_ins.json` — 보험 '잠든 보험금' 18초 (참고: 01·05·06·03·08·04·09·10)
  렌더: `node render.js "films/ins_v1.html" out 18 full 6` → `python3 audio_mix.py plans/film_ins.json out.wav` → ffmpeg 합치기
- `demo.html?m=02&o={...}` — 부품 단독 데모 (opts JSON으로 문구·색 교체)
- `render.js` — Playwright 렌더 (`sheet` 스틸 검수 / `full` 60fps × 서브프레임 6 → tmix)
- `audio_mix.py` — 음악 + 효과음 믹서 (효과음은 카탈로그의 '피크 시점'을 화면 사건에 맞춤, 사이드체인, -14 LUFS)
- `plans/*.json` — 부품 데모별 사운드 플랜

## 사운드 원칙
- 효과음·음악은 Mixkit 카탈로그(`sfx_catalog.json`, `music_catalog.json`)에서만 고른다. 파일은 재배포 금지 → 고객 PC가 url에서 직접 받아 로컬 캐시.
- 효과음은 파일 시작이 아니라 **피크**를 사건 시각에 맞춘다.
- 음악 드롭(카탈로그 `drops`)을 영상의 가장 큰 전환에 맞춘다.

## 렌더 비용 (2코어 컨테이너 기준)
프레임당 약 0.3초 → 5초 데모(서브프레임 6) ≈ 10분. 블러는 축소 버퍼(1/4·1/8·1/16)에서만.

## 실행 (고객 PC)
1. `npm install` (playwright, 손글씨 폰트)
2. `python fetch_audio.py` — 카탈로그 음원을 Mixkit에서 직접 받아 `cache/`에 저장
3. `node render.js "demo.html?m=03" out 4.8 full 6` (내장 서버 사용, `sheet` 모드로 스틸 검수 가능)
4. `python audio_mix.py plans/m03.json out.wav` → ffmpeg로 영상과 합치기

## 합격 부품 (2026-10-24 대표 확인)
2차(06~10)는 데모 전달, 대표 검수 대기.
